 Khusomaty (Daily Deal) App

An automated web scraping and price aggregation tool designed to extract daily promotional offers from major e-commerce platforms like Amazon and Noon. 

**Key Features**
* **Human-like Automation:** Utilizes customized Python bots (Selenium) designed to mimic human browsing behavior to bypass anti-bot detection systems.
* **Multi-Platform Support:** Independent bots handling platform-specific logic (`amazon_bot.py`, `noon_bot.py`).
* **Containerized Environment:** Fully deployable using Docker.
* **Database Integration:** Automated data handling and synchronization (`database_handler.py`).

**Tech Stack**
* **Backend:** Python
* **Frontend:** HTML, CSS, JavaScript
* **Deployment & Tools:** Docker, VBScript
